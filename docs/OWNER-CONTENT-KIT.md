# VowFound owner content kit

All entries below are drafts for completion, not statements of existing credentials, clients, results, staffing, or financial performance. Keep this file internal. The public sample plan is explicitly fictional.

## Practitioner profiles

Use Admin → Content → Copy → Practitioner profiles. Two slots are provided. A profile renders only when both name and biography are populated. Enter the biography and coverage first; enter the verified name last to publish. Clear the name to withdraw it.

For each practitioner collect:

- Public name and role.
- Qualifications, awarding body, dates, and verification record.
- Relevant experience, without unsupported years or client counts.
- Consultation languages and geographic/timezone coverage.
- Specific services they currently deliver and current capacity.
- Permission to publish their biography and any photograph.

Biography draft: “[Name] supports [audience] with [specific work]. Their background includes [verified training or experience]. Sessions focus on [approach and deliverables]. Consultations are available in [languages] for [coverage].”

Do not use generated headshots as photographs of real practitioners. Add a real, consented photograph when available.

## Booking setup

The booking page uses NEXT_PUBLIC_BOOKING_URL when configured. Otherwise it offers an inline consultation request through the existing contact backend. Requests are not confirmed appointments.

Set a real calendar URL and verify available slots, timezone display, cancellation, confirmation email, reminders, and the assigned practitioner's calendar. Do not enter a dummy calendar link.

## Matchmaking engagement worksheet

Complete with each client before accepting a search:

- Assigned practitioner and start date.
- Locations, relocation preferences, and essential requirements.
- Evidence that the search is feasible; decline or narrow scope where it is not.
- Number of introductions and written definition of “qualified”.
- Consent process and treatment of declined proposals.
- Review dates, pauses, completion date, and responsibilities.
- Fees, third-party costs, cancellation and extension terms.

This worksheet prompts operational decisions; it does not replace the existing agreement or create new contractual promises.
